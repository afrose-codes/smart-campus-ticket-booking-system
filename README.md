# Smart Campus Ticket Booking System 🎟️🏫

A full-stack **Spring Boot web application** designed to simplify campus event management and ticket booking for students and administrators.

The system provides secure authentication, OTP verification, QR-based ticket confirmation, AI chatbot support, and real-time event location tracking using maps.

---

# 🚀 Features

## 👤 User Authentication & Authorization
- Secure login and registration using Spring Security
- Role-based access for:
  - Admin
  - Student
- Password encryption using BCrypt

---

## 📅 Event Management
- View upcoming campus events
- Event details include:
  - Event title
  - Venue
  - Date & time
  - Available seats
  - Ticket price
- Filter events by category/type

---

## 🎟️ Event Ticket Booking
- Students can book tickets for events
- Seat availability validation before confirmation
- Prevents overbooking

---

## 📩 OTP Verification System
- OTP (One-Time Password) sent to user email during registration/login
- Secure verification before completing actions
- Enhances authentication and security

---

## 🔳 QR Code Ticket Confirmation
- Generates a unique QR Code after successful booking
- Used for:
  - Event entry verification
  - Fast admin check-in
  - Secure ticket validation

---

## 🗺️ Real-Time Event Location (Maps Integration)
- Displays event venue location using maps
- Helps students navigate to event locations easily
- Improves user experience

---

## 🤖 AI Chatbot Support
- Intelligent chatbot for assisting users
- Answers queries related to:
  - Events
  - Registrations
  - Ticket booking
  - Venue details
- Provides instant support

---

## ⭐ Feedback System
- Students can submit feedback after attending events
- Rating and comments supported
- Helps improve future campus events

---

## 📊 Admin Dashboard
- Manage events
- View registrations
- Monitor bookings
- Handle student participation
- Check-in users using QR verification
